# C++ Practice

Small standalone C++ exercises for hands-on practice.

## Topics

- Basics
- Algorithms
- Data structures
- Object-oriented programming
- Numerical methods
- Robotics
- Networking
- Utilities

## Compile an Example

    g++ -std=c++17 -Wall -Wextra -pedantic robotics/pid_controller.cpp -o pid_controller

Run:

    ./pid_controller

Each file is intentionally small so you can read it, predict what it does, compile it, modify it, and rerun it.
